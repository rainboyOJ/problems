# Use Fastify and Pug for server-rendered pages

The site will use Fastify with Pug templates for server-side rendering instead of a Vue single-page application. The project is a read-only problem browser with a small number of page types, and server-side rendering keeps the existing Node-based Markdown pipeline close to the filesystem, improves first-load and SEO behavior, and avoids adding client-side state and API plumbing before the product needs them. Vite remains as a static asset build tool for SCSS and focused browser-side JavaScript, while Vue is not part of the runtime page architecture. Small interactions such as theme switching and code copying can remain in focused browser-side JavaScript; Vue can be reconsidered if the product later gains substantially richer client-side workflows.
